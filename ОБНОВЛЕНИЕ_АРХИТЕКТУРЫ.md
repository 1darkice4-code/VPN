# ОБНОВЛЕНИЕ ПРОЕКТА - УБРАНА ТЕСТОВАЯ КОНФИГУРАЦИЯ

## Что изменено

### 1. Убран контейнер linuxserver/wireguard
- Теперь используется только wgREST для управления WireGuard
- wgREST создает и управляет WireGuard интерфейсом самостоятельно

### 2. Улучшена конфигурация wgREST
- Добавлена полная конфигурация устройства с правильными настройками
- Настроены iptables правила для NAT и форвардинга
- Добавлен порт 51830 для WireGuard

### 3. Убрана тестовая конфигурация из бота
- Бот теперь полностью зависит от wgREST
- Удалены все fallback конфигурации
- Улучшена обработка ошибок

### 4. Упрощены переменные окружения
- Убраны ненужные настройки WireGuard
- Оставлены только необходимые параметры для wgREST

## Как применить изменения на сервере

```bash
# 1. Получить обновления
git pull origin main

# 2. Остановить старые контейнеры
docker-compose down

# 3. Удалить старые volumes (если нужно)
docker volume rm vpn_wgrest_data

# 4. Обновить файл .env
cp vpn_bot/env.example vpn_bot/.env
nano vpn_bot/.env  # Укажите ваш BOT_TOKEN

# 5. Запустить новые контейнеры
docker-compose up -d

# 6. Проверить логи
docker logs wgrest
docker logs vpn_bot
```

## Проверка работы

После запуска в логах wgREST должны появиться:
```
✅ Устройство wg0 создано
```

А в логах бота:
```
✅ Конфиг получен через wgREST
```

## Возможные проблемы

1. **Ошибка создания устройства**: Проверьте права доступа и наличие WireGuard модуля
2. **Ошибка подключения к wgREST**: Проверьте сетевые настройки и токен авторизации
3. **Ошибка создания пира**: Убедитесь, что устройство создано успешно
