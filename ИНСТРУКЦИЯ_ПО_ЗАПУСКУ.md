# 📖 Инструкция по запуску VPN системы

## 🎯 Что было сделано

Система управления VPN полностью объединена и готова к работе:

✅ **Telegram бот** - для управления подписками  
✅ **WireGuard сервер** - VPN соединение  
✅ **wgREST API** - REST API для управления WireGuard  
✅ **PostgreSQL** - база данных  
✅ **Docker Compose** - оркестрация всех сервисов  

## 🚀 Быстрый старт (3 простых шага)

### 1️⃣ Настройка токена бота

Откройте файл `vpn_bot/.env` и укажите токен бота:

```env
BOT_TOKEN=ваш_токен_от_BotFather
```

> Как получить токен: найдите @BotFather в Telegram, отправьте `/newbot`, следуйте инструкциям.

### 2️⃣ Запуск системы

**Windows:**
```powershell
.\start.ps1
```

Или через PowerShell:
```powershell
.\setup.bat
docker-compose up -d
```

**Linux/Mac:**
```bash
chmod +x setup.sh start.sh
./setup.sh
docker-compose up -d
```

### 3️⃣ Получение ключа WireGuard

После запуска выполните:
```bash
docker exec wg cat /config/wg0.conf | grep PublicKey
```

Скопируйте значение и обновите в `vpn_bot/.env`:
```env
WG_SERVER_PUBLIC_KEY=скопированный_ключ
```

Перезапустите бота:
```bash
docker-compose restart vpn_bot
```

## 🎮 Полезные команды

### Запуск и остановка

```bash
# Запуск всех сервисов
docker-compose up -d

# Остановка
docker-compose down

# Остановка с удалением данных
docker-compose down -v

# Перезапуск
docker-compose restart
```

### Просмотр логов

```bash
# Все сервисы
docker-compose logs -f

# Только бот
docker-compose logs -f vpn_bot

# Только БД
docker-compose logs -f db

# Только WireGuard
docker-compose logs -f wg
```

### Статус сервисов

```bash
# Статус контейнеров
docker-compose ps

# Использование ресурсов
docker stats
```

### Работа с базой данных

```bash
# Подключение к БД
docker exec -it vpn_db psql -U vpn_bot_user -d vpn_bot_db

# В psql можно выполнить:
# \dt              - список таблиц
# \d users         - структура таблицы
# SELECT * FROM users; - запросы
```

## 🔍 Проверка работы

### 1. Проверьте статус контейнеров

```bash
docker-compose ps
```

Все должны быть в статусе `Up` или `Up (healthy)`.

### 2. Найдите бота в Telegram

Откройте Telegram, найдите вашего бота и отправьте `/start`.

### 3. Проверьте API

```bash
curl http://localhost:8080/v1/devices/
```

Должен вернуть JSON массив устройств.

## 🐛 Решение проблем

### Бот не запускается

**Проблема:** В логах ошибка подключения к БД

**Решение:**
```bash
# Подождите пока БД инициализируется (30-60 сек)
# Проверьте логи БД
docker-compose logs db

# Перезапустите бота
docker-compose restart vpn_bot
```

### Бот не отвечает в Telegram

**Проблема:** Бот игнорирует сообщения

**Решение:**
1. Проверьте токен в `vpn_bot/.env`
2. Проверьте логи: `docker-compose logs vpn_bot`
3. Перезапустите: `docker-compose restart vpn_bot`

### WireGuard не работает

**Проблема:** Невозможно подключиться к VPN

**Решение:**
```bash
# Проверьте конфигурацию
docker exec wg cat /config/wg0.conf

# Проверьте порт
sudo netstat -ulnp | grep 51830

# Перезапустите
docker-compose restart wg
```

### База данных не инициализируется

**Проблема:** Ошибки SQL при запуске

**Решение:**
```bash
# Полная пересоздание БД
docker-compose down -v
docker-compose up -d

# Проверьте SQL файлы
ls SQL/
```
