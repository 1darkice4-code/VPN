## 📋 Быстрая инструкция

### Шаг 1: Настройка токена бота

```bash
# Скопируйте пример конфигурации
cp vpn_bot/env.example vpn_bot/.env

# Отредактируйте .env
nano vpn_bot/.env
```

Укажите:
```env
BOT_TOKEN=ваш_токен_от_BotFather
```

### Шаг 2: Запуск системы

```bash
# Запуск всех сервисов
docker-compose up -d

# Проверка статуса
docker-compose ps
```

Все контейнеры должны быть `Up`:
- ✅ vpn_db
- ✅ wg  
- ✅ wgrest
- ✅ vpn_bot

### Шаг 3: Получение публичного ключа

```bash
# Подождите 30-60 секунд для полной инициализации WireGuard
sleep 45

# Получите публичный ключ
docker exec wg cat /config/wg0.conf | grep PublicKey

# Обновите .env
nano vpn_bot/.env
```

Добавьте в `.env`:
```env
WG_SERVER_PUBLIC_KEY=полученный_ключ_сверху
```

### Шаг 4: Перезапуск бота

```bash
docker-compose restart vpn_bot
```

### Шаг 5: Настройка IP сервера

Откройте `.env` и укажите реальный IP вашего сервера:
```env
WG_SERVER_ENDPOINT=ваш_внешний_ip:51830
```

Если у вас домен:
```env
WG_SERVER_ENDPOINT=vpn.example.com:51830
```

### Шаг 6: Файрвол

```bash
sudo ufw allow 51830/udp
sudo ufw allow 8080/tcp
sudo ufw reload
```

## 🐛 Troubleshooting

### Проблема: "wgREST недоступен"
```
⚠️ wgREST недоступен, используем демо-конфиг
```

**Решение**:
```bash
# Проверьте статус wgREST
docker-compose ps wgrest

# Перезапустите
docker-compose restart wgrest

# Проверьте логи
docker-compose logs wgrest
```

### Проблема: Бот не отвечает

**Решение**:
```bash
# Проверьте токен
cat vpn_bot/.env | grep BOT_TOKEN

# Проверьте логи
docker-compose logs vpn_bot

# Перезапустите бота
docker-compose restart vpn_bot
```

### Проблема: База данных не инициализируется

**Решение**:
```bash
# Полная перезагрузка
docker-compose down -v
docker-compose up -d

# Подождите 60 секунд
sleep 60

# Проверьте БД
docker exec vpn_db psql -U vpn_bot_user -d vpn_bot_db -c "\dt"
```

### Проблема: VPN не подключается

**Причины**:
1. ❌ Неправильный PublicKey сервера
2. ❌ Не открыт порт 51830/udp
3. ❌ Неправильный Endpoint в конфиге

**Решение**:
```bash
# 1. Проверьте публичный ключ
docker exec wg cat /config/wg0.conf | grep PublicKey

# 2. Обновите в .env
# 3. Перезапустите бота
docker-compose restart vpn_bot

# 4. Проверьте файрвол
sudo ufw status | grep 51830

# 5. Тестируйте подключение
# (скачайте конфиг заново через бота)
```
