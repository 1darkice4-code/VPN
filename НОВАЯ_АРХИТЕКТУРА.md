# НОВАЯ АРХИТЕКТУРА VPN ПРОЕКТА

## Обзор

Проект переделан под правильную продакшн архитектуру:
- **WireGuard** работает как системный сервис на хосте
- **wgREST** работает в контейнере и управляет WireGuard через API
- **Telegram бот** работает в контейнере и взаимодействует с wgREST

## Компоненты

### 1. WireGuard (системный сервис)
- **Расположение**: Хост система
- **Сервис**: `wg-quick@wg0`
- **Порт**: 51830/udp
- **Конфигурация**: `/etc/wireguard/wg0.conf`
- **Управление**: systemctl

### 2. wgREST (контейнер)
- **Расположение**: Docker контейнер
- **Порт**: 8080/tcp
- **Сеть**: host network
- **Функции**: API для управления WireGuard пирами

### 3. vpn_bot (контейнер)
- **Расположение**: Docker контейнер
- **Сеть**: bridge network
- **Функции**: Telegram бот для пользователей

### 4. PostgreSQL (контейнер)
- **Расположение**: Docker контейнер
- **Порт**: 5432/tcp
- **Функции**: База данных пользователей и подписок

## Установка и настройка

### 1. Установка WireGuard как системного сервиса

```bash
# Сделать скрипт исполняемым
chmod +x install_wireguard_service.sh

# Запустить установку (требует root)
sudo ./install_wireguard_service.sh
```

### 2. Запуск Docker контейнеров

```bash
# Получить обновления
git pull origin main

# Запустить контейнеры
docker-compose up -d

# Проверить статус
docker-compose ps
```

### 3. Проверка системы

```bash
# Сделать скрипт исполняемым
chmod +x check_vpn_system.sh

# Запустить проверку
./check_vpn_system.sh
```

## Управление

### WireGuard сервис
```bash
# Статус
sudo systemctl status wg-quick@wg0

# Запуск
sudo systemctl start wg-quick@wg0

# Остановка
sudo systemctl stop wg-quick@wg0

# Перезапуск
sudo systemctl restart wg-quick@wg0

# Логи
sudo journalctl -u wg-quick@wg0 -f
```

### Docker контейнеры
```bash
# Статус
docker-compose ps

# Запуск
docker-compose up -d

# Остановка
docker-compose down

# Перезапуск
docker-compose restart

# Логи
docker-compose logs -f
```

### Проверка системы
```bash
# Полная проверка
./check_vpn_system.sh

# Проверка WireGuard
sudo wg show wg0

# Проверка wgREST
curl http://localhost:8080/version
```

## Troubleshooting

### WireGuard не запускается
```bash
# Проверить конфигурацию
sudo wg-quick strip wg0

# Проверить логи
sudo journalctl -u wg-quick@wg0 -n 50

# Переустановить сервис
sudo ./install_wireguard_service.sh
```

### wgREST не видит устройство
```bash
# Проверить статус WireGuard
sudo systemctl status wg-quick@wg0

# Проверить устройство
sudo wg show wg0

# Перезапустить wgREST
docker-compose restart wgrest
```

### Бот не может подключиться к wgREST
```bash
# Проверить доступность wgREST
curl http://localhost:8080/version

# Проверить логи бота
docker logs vpn_bot

# Проверить сеть
docker exec vpn_bot ping host.docker.internal
```
